# KaiHub 脚本中心

一个基于 ChronixHub V3 的 Roblox 多功能脚本中心。

## 功能特性

- 完整的玩家属性修改系统（移速、跳跃、血量等）
- 多种实用工具（穿墙、无限跳、飞行、透视等）
- 支持多种热门游戏的专用功能
- 内置音乐播放器和音频检查器
- 脚本中心，集成多个第三方脚本
- 玩家传送和路径点系统
- 实用的执行器和聊天监控功能
- 手机端虚拟按键支持

## 使用方法

在 Roblox 执行器中运行：

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/你的用户名/KaiHubjiaoben/refs/heads/main/Ui.lua"))()
```
